# Kiosk

Ways to turn a computer into a dedicated kiosk: a screen that shows one web page
full-screen, all the time, with no desktop or browser controls. Typical uses are wall-mounted
dashboards and control panels.

There are many ways to build a kiosk, depending on the hardware, operating system and
browser. This repository holds setups that have been built and used, each in its own
directory:

| Directory | Platform |
|---|---|
| [`ubuntu-cage-kiosk/`](ubuntu-cage-kiosk/) | Ubuntu 24.04 LTS (amd64), the cage compositor and Google Chrome. Touch screens or laptops; audio autoplay, day/night dimming, unattended restart. |

## Status

This is mostly a reference: working setups to read, copy and adapt. Issues, suggestions and
pull requests are welcome. Requests outside what a setup is meant to cover may be declined,
but forks are encouraged.
